# SNÖRES

Site vitrine responsive de la marque SNÖRES, intégré à partir des maquettes Figma.

## Fichiers
- `index.html` : contenu et structure sémantique
- `styles.css` : styles généraux et palette
- `components.css` : composants et sections
- `responsive.css` : adaptations mobile et préférences de mouvement
- `script.js` : menu, recherche, aperçu produit et panier de démonstration
- `assets/` : logo et photos SNÖRES

## Lancer le site
Aucune dépendance ni compilation : ouvrir `index.html` avec un serveur statique local (`python3 -m http.server 8000`).

## Accessibilité
Balises sémantiques, texte alternatif, navigation au clavier, focus visible et animation réduite. Une vérification RGAA complète nécessite encore des tests manuels.

## Informations importantes
Le panier est une démonstration locale : aucun paiement ni stockage permanent n'est connecté. Les prix et conditions de livraison doivent être vérifiés avant toute commercialisation.
